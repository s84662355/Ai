Go 代码说明 - 椭圆拟合动画

此 Go 代码实现了一个椭圆拟合动画，借助梯度下降算法持续优化椭圆方程的参数，让其尽可能契合给定的带标签坐标点。下面是对代码各部分的详细说明：

8. 辅助函数

  • drawAxes：绘制坐标轴和刻度。
  • drawPoints：绘制所有带标签的坐标点，根据标签设置不同的颜色。
  • drawCurve：绘制当前拟合的椭圆曲线，通过网格采样找到曲线上的点并连接。
  • drawInfo：显示训练信息，包括迭代次数、损失值和椭圆方程的参数。
  • sigmoid：实现 sigmoid 函数，用于将值映射到概率。
  • computeLoss：计算交叉熵损失，评估模型的拟合效果。
  • computeGradient：计算梯度向量，用于梯度下降算法更新参数。
  • train：梯度下降训练函数，根据给定的学习率和迭代次数进行训练。

椭圆拟合算法详细说明

1. 椭圆方程表示

算法使用一般二次曲线方程表示椭圆：

Ax² + By² + Dx + Ey + F = 0

其中参数 A、B、D、E、F 决定了椭圆的形状、大小和位置。

2. 点到椭圆的分类

对于任意点 (x, y)，计算其代数距离：

d = Ax² + By² + Dx + Ey + F

根据 d 的符号判断点是否在椭圆内：

  • d > 0：点在椭圆外
  • d = 0：点在椭圆上
  • d < 0：点在椭圆内

3. 二分类模型

算法将椭圆拟合问题转化为二分类问题：

  • 标签 1：点在椭圆内
  • 标签 0：点在椭圆外

使用 sigmoid 函数将代数距离转换为概率：

P(class=1) = σ(-d) = 1 / (1 + e^d)

4. 损失函数

采用二元交叉熵损失函数：

L = - [y·log(P) + (1-y)·log(1-P)]

其中 y 是真实标签，P 是预测概率。

5. 梯度下降优化

算法通过计算损失函数对各参数的偏导数来更新参数：

∂L/∂A = (P-y)·(-x²)
∂L/∂B = (P-y)·(-y²)
∂L/∂D = (P-y)·(-x)
∂L/∂E = (P-y)·(-y)
∂L/∂F = (P-y)·(-1)

参数更新规则：

θ = θ - α·∂L/∂θ

其中 θ 代表参数 A、B、D、E、F，α 是学习率。

6. 算法流程

  1. 初始化：随机初始化参数 A、B、D、E、F
  2. 迭代优化：
    • 计算每个点到当前椭圆的代数距离
    • 通过 sigmoid 函数将距离转换为概率
    • 计算交叉熵损失
    • 计算损失对各参数的梯度
    • 根据梯度更新参数
  3. 终止条件：达到最大迭代次数或损失收敛

综上所述，该代码通过梯度下降算法不断优化椭圆方程的参数，使其尽可能拟合给定的带标签坐标点，并通过 ebiten 库实现了动画效果，实时展示训练过程和拟合结果。
