逻辑回归可视化代码说明

项目概述

这段Go语言代码实现了一个二元逻辑回归分类器的可视化程序，使用ebiten游戏引擎展示分类过程。主要功能包括：

  • 生成二维平面上的分类数据点，围绕一条真实直线分布
  • 使用梯度下降算法优化逻辑回归模型参数（a、b、c）
  • 实时可视化展示分类边界的拟合过程，包括样本点、真实边界和拟合边界
  • 显示训练进度、交叉熵损失值和模型参数的变化

该项目非常适合理解逻辑回归和分类问题的工作原理，通过可视化可以直观地看到模型如何学习区分两个类别的决策边界。

核心算法

逻辑回归模型

逻辑回归模型通过逻辑斯蒂函数（sigmoid）将线性组合映射到[0,1]区间的概率值：

p = 1 / (1 + e^-(a + b·x + c·y))

其中：

  • p 是属于类别1的概率
  • x, y 是输入特征（二维坐标）
  • a 是偏置参数
  • b, c 是特征的权重参数

代码实现：

func logistic(a, b, c, x, y float64) float64 {
    g := a + b*x + c*y
    return 1.0 / (1.0 + math.Exp(-g))
}

交叉熵损失函数

使用交叉熵损失函数衡量分类效果：

L = -(1/n)·Σ(yi·log(pi) + (1-yi)·log(1-pi))

代码实现：

func crossEntropyLoss(yTrue []int, xData, yData []float64, a, b, c float64) float64 {
    m := len(yTrue)
    sumLoss := 0.0
    for i := range yTrue {
        p := logistic(a, b, c, xData[i], yData[i])
        if yTrue[i] == 1 {
            sumLoss -= math.Log(p)
        } else {
            sumLoss -= math.Log(1 - p)
        }
    }
    return sumLoss / float64(m)
}

梯度下降

通过计算损失函数对各参数的梯度，沿梯度反方向更新参数：

a = a - lr·∂L/∂a
b = b - lr·∂L/∂b
c = c - lr·∂L/∂c

梯度计算与参数更新的代码实现：

func (g *Game) Update() error {
    if currentIter < totalIterations {
        gradA := gradientA(labels, xData, yData, a, b, c)
        gradB := gradientB(labels, xData, yData, a, b, c)
        gradC := gradientC(labels, xData, yData, a, b, c)

        a -= learningRate * gradA
        b -= learningRate * gradB
        c -= learningRate * gradC

        loss = crossEntropyLoss(labels, xData, yData, a, b, c)
        currentIter++
    }
    return nil
}

分类边界

当p=0.5时，得到分类边界：a + b·x + c·y = 0，即y = (-a - b·x)/c。随着训练进行，模型学习到的边界会逐渐接近真实边界。

坐标转换

数学坐标到屏幕坐标的映射：

// 坐标转换：数学坐标转屏幕坐标
func mathToScreen(x, y float64) (float64, float64) {
    screenX := (x - xMinPlot) / (xMaxPlot - xMinPlot) * float64(screenWidth)
    screenY := (1 - (y - yMinPlot)/(yMaxPlot - yMinPlot)) * float64(screenHeight)
    return screenX, screenY
}

该函数确保数学坐标系中的点能正确显示在屏幕上，考虑了不同的坐标方向和范围。

参数说明

关键参数

参数 含义 默认值 调整建议
numPoints 数据点数量 2000 数据越多，模型越稳定，但计算量越大
learningRate 学习率 0.006 过大会导致不收敛，过小会导致收敛慢
totalIterations 总迭代次数 200000 足够大以确保收敛，可根据损失变化调整
noiseMax 噪声最大值 1.5 值越大，数据越分散，分类越困难
trueSlope 真实边界斜率 1.342 定义真实分类边界的斜率
trueIntercept 真实边界截距 2.45 定义真实分类边界的截距
