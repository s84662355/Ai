均值漂移聚类可视化代码说明

项目概述

这段Go语言代码实现了均值漂移聚类算法的可视化程序，使用ebiten游戏引擎展示聚类过程。主要功能包括：

  • 生成具有自然聚类特性的二维数据点
  • 使用均值漂移算法自动发现数据中的聚类中心
  • 可视化展示每个点向聚类中心的漂移过程
  • 使用动画效果平滑过渡漂移轨迹
  • 自动确定聚类数量，无需预先指定
  • 显示当前迭代次数和收敛状态

该项目非常适合理解均值漂移聚类算法的工作原理，通过可视化可以直观地看到算法如何自动发现数据中的密度中心，并将数据点分配到不同的聚类中。与K-means不同，均值漂移不需要预先指定聚类数量，而是根据数据密度自动确定。

核心算法

均值漂移算法

均值漂移是一种基于密度估计的非参数聚类方法，它的核心思想是：

每个数据点都会向数据密度更高的区域"漂移"，最终收敛到密度峰值（模式点）

算法原理

给定一个点x，均值漂移迭代更新公式为：

xi+1 = Σj=1n K(xi-xj)·xj / Σj=1n K(xi-xj)

其中：

  • K是核函数（通常使用高斯核）
  • n是数据点数量
  • xj是第j个数据点

代码实现

核心算法在Step()方法中实现：

func (ms *MeanShift) Step() bool {
    converged := true
    bandwidthSq := ms.bandwidth * ms.bandwidth // 带宽平方（优化计算）
    
    // 对每个点执行一次漂移计算
    for i := range ms.modes {
        currentMode := ms.modes[i]
        sumX, sumY := 0.0, 0.0
        totalWeight := 0.0
        
        // 计算带宽范围内的加权平均
        for _, p := range ms.points {
            distSq := (p.X-currentMode.X)*(p.X-currentMode.X) + (p.Y-currentMode.Y)*(p.Y-currentMode.Y)
            if distSq <= bandwidthSq {
                // 高斯核函数权重
                weight := math.Exp(-distSq / (2 * bandwidthSq))
                sumX += p.X * weight
                sumY += p.Y * weight
                totalWeight += weight
            }
        }
        
        // 计算新的模式点
        if totalWeight > 0 {
            newMode := Point{
                X: sumX / totalWeight,
                Y: sumY / totalWeight,
            }
            
            // 检查是否收敛（移动距离小于阈值）
            if distance(newMode, currentMode) > 0.01 {
                ms.modes[i] = newMode
                converged = false
            }
        }
    }
    
    ms.iterations++
    return converged
}

高斯核函数

在代码中使用的高斯核函数：

weight := math.Exp(-distSq / (2 * bandwidthSq))

高斯核函数的特点：

  • 距离越近的点权重越大
  • 带宽参数控制了影响范围
  • 随着距离增加，权重呈指数衰减

算法特性

均值漂移算法的主要优点：

  • 不需要预先指定聚类数量
  • 能够发现任意形状的聚类
  • 对噪声和离群点具有鲁棒性
  • 算法自动确定聚类中心的位置
主要缺点：
  • 计算复杂度较高（O(n²)）
  • 带宽参数需要手动调整
  • 可能会收敛到局部密度峰值

动画控制

动画效果通过Update()和UpdateAnimation()方法控制：

func (g *Game) Update() error {
    if g.ms.converged {
        return nil
    }
    
    // 动画进度更新
    g.animProg += g.animSpeed
    if g.animProg >= 1.0 {
        // 动画结束，执行下一步均值漂移
        g.animProg = 0
        g.ms.converged = g.ms.Step()
        g.ms.currentStep++
    }
    
    // 更新当前动画帧的显示状态
    g.ms.UpdateAnimation(g.animProg)
    return nil
}

关键动画逻辑：

  • 使用animProg变量跟踪动画进度（0-1）
  • 每次更新增加animSpeed（0.03）
  • 动画完成后执行均值漂移迭代步骤
  • 在UpdateAnimation()中使用线性插值计算当前显示位置

参数说明

关键参数

参数 含义 默认值 调整建议
bandwidth 高斯核函数带宽 5.0 控制聚类粒度，较大值产生更少的聚类，较小值产生更多的聚类
width, height 窗口尺寸 800x600 根据需要调整窗口大小
animSpeed 动画速度 0.03 值越大动画越快，可调整为0.01-0.05之间
total 数据点总数 600 数据越多，聚类效果越明显，但计算量也越大
clusters 生成的自然聚类数量 5 控制初始数据的聚类特性，用于测试算法效果

  • 较大的bandwidth会导致更少、更大的聚类
  • 较小的bandwidth会导致更多、更小的聚类
